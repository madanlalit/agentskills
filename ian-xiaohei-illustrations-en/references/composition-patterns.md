# Composition Patterns and Originality Rules

## Base structure types

Pick one structure per image; do not mix many.

### Workflow

Best for: input -> process -> output, content production, AI workflows, automation chains.

Draw it: input on the left, Xiaohei or a strange machine in the middle, output on the right, orange arrows showing the main flow.

### System slice

Best for: information sources, filters, databases, renderers, agent system slices.

Draw it: only 3-5 core modules, Xiaohei participates in one of the key actions.

### Before / after

Best for: chaos vs. order, manual vs. automated, scattered vs. gathered, anxious vs. stable.

Draw it: chaos on the left, stable on the right, an orange arrow in the middle. Characters can be more exaggerated.

### Character state

Best for: user pain points, creator state, too many tools, information anxiety, stuck vs. running.

Draw it: 2-4 small states, each with a short label.

### Concept metaphor

Best for: content factory, information warehouse, internal black box, workflow machine, automated daily report.

Draw it: one large strange object or machine, a few inputs, one output. Should have a memory hook.

### Method layers

Best for: methodology frameworks, system levels, capability stacks, content system layers.

Draw it: layered boxes, not a formal pyramid; Xiaohei nearby hauling bricks or assembling.

### Map route

Best for: idea to launch, user journey, content handoff path, learning path.

Draw it: one curving path, a few nodes, Xiaohei pulling the line or walking.

### Mini comic panels

Best for: failure to success, real process,吐槽 (lament), before/after change.

Draw it: 2-4 small scenes, each panel shows only one action.

## Original-metaphor generation method

Always invent the metaphor fresh from the current article. Do not copy old images.

### Three steps

1. Replace the abstract concept with a physical action: stuck, leaked, weighted, sorted, settled, fermented, opened, folded, unpacked, recycled.
2. Replace the system structure with a low-tech object: a broken machine, a cardboard box, a drawer, a water pipe, a mailbox, a strange gauge, a scale, a well, a ladder, a weird workstation.
3. Let Xiaohei do the action: not standing nearby, but stuck inside a machine, pulling the wrong wire, guarding a gate, hauling, patching, weighing, holding a ladder, recording, or stuffing something into a strange device.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water pipe, ball of string, sluice gate, turntable, black box, hole punch, pasta press, clothesline, weird workstation.
- Use only 1-2 per image. Do not pile them up.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, stitch, cut, twist, guard, push, catch, disassemble, mark, recycle.
- Actions must serve the core meaning, do not be strange for the sake of strange.

## No-recycling rules

Do not default to copying any prior case. The reference images are for style calibration only — line density, whitespace, color restraint, Xiaohei's character.

Unless the user explicitly says "copy this / reproduce this composition / edit from this case", do not directly reuse these old compositions:

- Conveyor belt with two breakpoints.
- Xiaohei pulling a judgment lever inside a content machine.
- Xiaohei turning into a funnel that sorts traffic / trust / conversion.
- Xiaohei slicing a material fish.
- Xiaohei leading a handoff path.
- Xiaohei pulling three layers of information sources.
- Three Xiaoheis holding a megaphone / building a bridge / opening a door.
- Xiaohei stamping a script toolbox.
- Xiaohei holding a sign while looking down a common-pit path.

Same theme still needs a new metaphor. For example, "handoff path" does not have to be a route — it could be Xiaohei fastening a content tail onto a door handle. "One-to-many reuse" does not have to be a fish — it could be Xiaohei pressing a paper ball into several shapes.
