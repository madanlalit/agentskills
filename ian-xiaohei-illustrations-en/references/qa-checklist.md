# QA Checklist

## Must pass

- It is 16:9 horizontal.
- Background is clean white.
- Xiaohei is present.
- Xiaohei performs the core action, not just decoration.
- Does not recycle an old case composition; a new metaphor is generated for the current article.
- The frame is surreal, creative, interesting.
- Clean and sparse; subject does not exceed about 60% of the canvas.
- One image shows only one core structure.
- English annotations are few, short, and legible.
- Orange is used only for the main path or arrows.
- Red is used only for emphasis, problems, reminders, or results.
- Blue is used only for secondary notes, feedback, or system state.

## Failure signals

Regenerate or surgically edit if any of these appear:

- A title like "Common Pitfalls / Workflow / System Architecture / Roadmap" sits in the top-left.
- Xiaohei looks like a mascot, emoji, or cute cartoon.
- The frame looks like a slide deck, course slide, or formal flowchart.
- Too many elements, too many arrows, too many nodes.
- Text turns into a paragraph-length explanation.
- Background has paper texture, shadow, gradient, beige, or noise.
- Real UI screenshots or sci-fi interface look.
- Severe misspellings or unreadable annotations.
- Frame is too stiff with no absurd metaphor.
- Composition is too similar to a prior reference case.

## Iteration methods

- Too generic: make Xiaohei the actor, add one strange-but-coherent metaphor.
- Too complex: delete nodes, keep one action and 3-5 short labels.
- Too cute: emphasize deadpan, blank serious expression, not cute, not mascot.
- Too slide-like: remove titles, frames, neat grids, and excess arrows; switch to a hand-drawn scene.
- Too similar to an old case: keep the core meaning, swap the main object and Xiaohei's action.
- Garbled text: prefer a local edit; if too much is wrong, regenerate with fewer labels.

## Quality bar

A high-quality image should make the reader first feel "huh, that's odd", then understand the structure within 1 second.

If the first impression reads like a tutorial page rather than a strange product sketch on a white sheet, it fails.
