# Prompt Examples

These prompts can be copied directly into the agent.

## Plan only — no generation

```text
Use $ian-xiaohei-illustrations-en to plan first; do not generate any images yet.

Analyze the article below and decide where illustrations add value. Output a shot list of about 5 illustrations. For each one specify:
- which paragraph it should follow
- topic
- core meaning
- structure type
- what Xiaohei is doing in the frame
- suggested elements
- suggested short English label words

<paste article>
```

## Generate article illustrations

```text
Use $ian-xiaohei-illustrations-en to generate 4 Xiaohei surreal article illustrations for the article below.

Requirements: 16:9 horizontal, pure white background, black hand-drawn line art, sparse red/orange/blue handwritten English annotations. Each image shows only one core structure. No slide-deck infographic look, no cute cartoons.

<paste article>
```

## Strategy for a long article

```text
Use $ian-xiaohei-illustrations-en to plan illustrations for this long article.

Do not distribute illustrations evenly. Pick only the cognitive anchors: core judgments, input/output loops, before/after, common pitfalls, handoff paths. Default to 6-8 illustrations, output a shot list first, do not generate images.

<paste article>
```

## One concept, one image

```text
Use $ian-xiaohei-illustrations-en to generate one 16:9 article illustration for this claim:

"Trust is not shouted into existence — it is laid down, one piece of evidence at a time."

The frame should be surreal but clean. Xiaohei must perform the core action. At most 5 short English labels.
```

## Workflow-themed illustration

```text
Use $ian-xiaohei-illustrations-en to illustrate "turning one raw source of material into three kinds of content: traffic, trust, and conversion".

Do not draw a formal flowchart. Do not recycle the prior "one fish, many meals" composition. Invent a fresh low-tech metaphor and let Xiaohei perform the core action.
```

## Edit: remove a title

```text
Use $ian-xiaohei-illustrations-en to edit this image.

Remove the "Workflow / Process" title and underline in the top-left corner. Keep everything else exactly the same. Do not add any new text or objects.
```

## Edit: strengthen Xiaohei's involvement

```text
Use $ian-xiaohei-illustrations-en on this image. The direction is right, but Xiaohei feels decorative.

Keep the core meaning the same and regenerate a version where Xiaohei is the one actually driving the structure forward. Make it stranger, but keep it pure white, clean, and low on text.
```

## Generate a style sample set

```text
Use $ian-xiaohei-illustrations-en to output 5 Xiaohei article illustrations on different topics.

Topics: information overload, product validation, content compounding, one-person company, building trust. Generate each one separately, do not stitch them into a single image.
```
