## About this English adaptation

This English adaptation lives in the `ian-xiaohei-illustrations-en/` directory of
`agentskills` and is derived from `helloianneo/ian-xiaohei-illustrations`.
The adaptation translates the workflow, style rules, IP description, composition
patterns, prompt template, QA checklist, and example prompts into English, and
swaps the in-image label language from Chinese to English so the skill is
usable for English-language articles.

It does not bundle any of the original example images. To use the original
calibration samples, fetch them from the upstream repository.
